# План функций

Реализуем последовательно.

Текущий этап: SVG RGB и PDF RGB/CMYK реализованы в версии 0.2.0. CMYK использует локальный конвертер; импорт в Figma и PDF с текстом требуют ручной проверки (см. README). AI/CDR отложены по согласованию.

## 1. Расширенный экспорт выделенных слоёв

Запрошено:
- SVG / AI / PDF / CDR.
- Выбор CMYK / RGB.
- Чекбокс «Перевод текста в кривые».
- При выключенном чекбоксе — редактируемый текст.

Ограничения и решения для обсуждения:
- Figma Plugin API экспортирует SVG и PDF напрямую; нативного экспорта AI/CDR и CMYK нет.
- SVG поддерживает `svgOutlineText`: кривые или текстовые элементы. Для воспроизведения редактируемого текста нужны соответствующие шрифты в целевой программе.
- PDF API не предоставляет аналогичный переключатель текста; нужно отдельно реализовать и проверить выбранный способ сохранения/перевода текста.
- Настоящие AI/CDR требуют отдельного пути конвертации и проверки в целевых редакторах. Переименование расширения не считается конвертацией.
- CMYK требует отдельного цветового преобразования с целевым ICC-профилем; согласовать требования типографии и способ выполнения конвертации.

Предложения, ещё не утверждены:
- Каждый выделенный слой отдельным файлом или всё выделение одной композицией.
- ZIP для пакетного экспорта, шаблон имён и обработка совпадающих имён.
- Для печати: физические размеры, вылеты, метки реза, ICC-профиль.
- Отчёт о шрифтах и потенциально проблемных эффектах.

Первое уточнение: нужны именно нативные .ai/.cdr или достаточно файлов, которые открываются и редактируются в Illustrator/CorelDRAW? Какие версии программ используются?

## 2. Переименование слоёв

Механика пока не определена. Возможные варианты для обсуждения: префикс/суффикс, нумерация, поиск и замена, применение к вложенным слоям, предпросмотр.

## 3. Замена текста в выделенных участках

Уточнить: поиск/замена или полная подстановка; обработка вложенных текстовых слоёв; регистр; сохранение смешанного форматирования.

## 4. Настройка выделенных картинок

Запрошены contain / fit / cover. Уточнить смысл отдельных режимов: contain и fit часто означают одно и то же — вписать целиком; cover — заполнить с обрезкой. В Figma определить соответствие FIT / FILL / CROP / TILE после уточнения.
