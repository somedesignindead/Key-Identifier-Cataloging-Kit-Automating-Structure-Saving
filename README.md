# Layer Export — Figma Plugin

Первая функция проекта: экспорт выделенных слоёв в SVG и PDF. Последующие функции: переименование слоёв, замена текста, режимы изображений — см. ROADMAP.md.

## Что работает

| Режим | Как создаётся | Конвертер |
|---|---|---|
| SVG, RGB, текст или кривые | Нативный SVG-экспорт Figma | Не нужен |
| PDF, RGB, кривые | Нативный PDF-экспорт Figma | Не нужен |
| PDF, RGB, текст | SVG с текстом → локальный Chromium → PDF | Нужен |
| PDF, CMYK | PDF → локальный Ghostscript с выбранным ICC | Нужен |

Каждый выбранный слой или фрейм становится отдельным файлом. Вложенный выбранный слой не дублируется, если выбран его родитель. Одинаковые имена получают числовые суффиксы. Несколько результатов можно скачать одним ZIP. Исходный документ не изменяется.

## Быстрый запуск на этом Mac

В рабочей папке проекта зависимости, Ghostscript и модуль Chromium уже установлены. Сборка лежит в `dist/`.

1. Откройте Figma Desktop и редактируемый файл Figma Design.
2. **Plugins → Development → Import plugin from manifest…** — выберите `manifest.json` из этой папки. Если проект уже импортирован, перезапустите плагин; при ошибке новых сетевых разрешений импортируйте manifest повторно.
3. Для CMYK или PDF с текстом дважды щёлкните **Запустить конвертер.command**. Альтернатива: в терминале из папки проекта выполните `npm run converter`.
4. Оставьте окно конвертера открытым. Скопируйте выведенный **код подключения**.
5. В Figma запустите **Plugins → Development → Layer Export**, выберите слои, формат и цвет. Вставьте код подключения в одноимённое поле. Нажмите «Проверить подключение».
6. Для CMYK выберите **Профиль типографии…** и файл `.icc` / `.icm` либо базовый профиль для теста.
7. Нажмите «Экспортировать», дождитесь завершения и скачайте результат по появившимся ссылкам.

Конвертер слушает только `127.0.0.1:47831`, требует код текущего запуска и не отправляет макеты во внешнюю сеть. Код меняется при перезапуске конвертера. Если Figma/macOS запрашивает доступ к локальной сети, он нужен для этой связи. Остановка конвертера: Ctrl+C в его окне.

В manifest нет чужого ID. Если Figma требует ID при импорте, создайте **New plugin → Custom UI** во временной папке и перенесите только выданное поле `id` в manifest этого проекта.

## Установка из ZIP на другом компьютере

ZIP содержит исходники, lockfile и готовую сборку, но не большие локальные зависимости и бинарники. Основной поддерживаемый сценарий этой версии — macOS.

Нужен Node.js 20 или новее. Из распакованной папки:

```sh
npm ci
npm run setup:gs
npm run setup:browser
npm run build
npm run converter
```

`setup:gs` скачивает официальный Ghostscript 10.08.0, проверяет SHA-256, собирает его в `.runtime/ghostscript` и сохраняет исходники с лицензией в `.runtime/gs-source`. Нужны `make` и C-компилятор (на macOS — Command Line Tools for Xcode). Если их нет, установите инструменты разработчика либо установите актуальный Ghostscript отдельно через `brew install ghostscript`.

`setup:browser` устанавливает Chromium для PDF с текстом в `.runtime/browsers`. Для PDF с кривыми этот компонент не нужен. Поддержка Windows не проверена; для установленного Ghostscript можно задать `GS_BIN` полным путём к `gswin64c.exe`, конвертер запускать через npm.

## Цвет, текст и ограничения

- **SVG — только RGB (sRGB).** Выбор CMYK доступен для PDF.
- **CMYK — реальное ICC-преобразование**, включая векторные цвета и растровые изображения. ICC-профиль встраивается как OutputIntent; файл не заявляется как PDF/X. Базовый профиль нужен для проверки механики, а для тиража требуется профиль вашей типографии.
- В этой версии используются относительный колориметрический метод и компенсация чёрной точки. Вылеты, метки реза, специальные краски, управление оверпринтом и PDF/X пока не реализованы.
- Галочка «Перевести текст в кривые» сохраняет внешний вид через нативный экспорт Figma. Без галочки SVG сохраняет `<text>`, а PDF собирается из SVG локальным Chromium.
- Для PDF с текстом шрифты должны быть установлены на компьютере конвертера. Для последующего редактирования нужны подходящие шрифты и в целевой программе. Сложные эффекты могут растрироваться вместе с затронутым текстом; абзацы могут разбиваться на отдельные текстовые фрагменты. Проверяйте такой результат в целевом редакторе.
- Для PDF с текстом принята геометрия 1 единица SVG/Figma = 1 pt; максимальная сторона 14400 pt. SVG сохраняет нативные размеры. Перед печатью сверьте физические размеры с заданием типографии.
- Общий исходный объём одного экспорта ограничен 100 МБ. При ошибке CMYK RGB-файл не выдаётся под видом CMYK.

## Проверено в этой среде

- TypeScript и сборка обеих частей плагина.
- 8 автоматических проверок: выделение, имена, форматы, сообщения, ZIP, локальный API и валидация ICC.
- Реальная конвертация тестового RGB PDF в CMYK: CMYK-операторы вместо RGB, встроенный ICC на 4 канала, сохранение русскоязычного текста и размеров страницы. Выполнен визуальный просмотр.
- Интерфейс проверен в браузерном стенде с имитацией сообщений Figma.

Не проверено: импорт и запуск в настоящем Figma Desktop; полный путь SVG → PDF с текстом. В среде Codex запуск отдельного Chromium блокируется ограничением macOS sandbox. Для проверки этого пути запустите конвертер обычным способом через `.command` или терминал.

## Разработка

```sh
npm run dev       # наблюдение и пересборка src/
npm run typecheck
npm test
```

После изменений перезапускайте плагин в Figma. Основные модули:

- `src/code.ts` — точка входа Figma и обработка сообщений.
- `src/core/export.ts` — экспорт выбранных корневых слоёв.
- `src/shared/messages.ts` — типы и проверки обмена UI ↔ Figma.
- `src/ui.ts`, `src/ui.html`, `src/ui/` — настройки, связь с конвертером, скачивание и ZIP.
- `converter/server.mjs` — локальный HTTP API с авторизацией.
- `converter/convert.mjs` — PDF с текстом и ICC-конвертация в CMYK.
- `converter/profiles.mjs` — валидация и выбор профиля.
- `scripts/` — сборка и установка локальных компонентов.

Параметры среды: `GS_BIN` — путь к Ghostscript; `CMYK_PROFILE` — путь к базовому CMYK ICC; `PLAYWRIGHT_BROWSERS_PATH` — необязательный каталог браузера. Пользовательский профиль из интерфейса имеет приоритет.

Технические источники: [Figma ExportSettings](https://developers.figma.com/docs/plugins/api/ExportSettings/), [ограничения PDF Figma](https://help.figma.com/hc/en-us/articles/13402894554519-Export-formats-and-settings-for-static-designs), [Ghostscript pdfwrite](https://ghostscript.readthedocs.io/en/master/VectorDevices.html). Ghostscript распространяется отдельно по лицензии Artifex AGPL/commercial; перед распространением собственного пакета с его бинарником учитывайте условия поставщика.
